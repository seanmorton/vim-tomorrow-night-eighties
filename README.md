This is my own version of the [Tomorrow Night Eighties Theme](https://github.com/chriskempson/tomorrow-theme/blob/master/vim/colors/Tomorrow-Night-Eighties.vim) for Vim with a few tweaks & additions:
* vim-fzf colors
* vim-go-syntax additional Go colors
* Diff highlighting similar to Github

## Installation with Pathogen
```
cd ~/.vim/bundle && git clone https://github.com/seanmorton/vim-tomorrow-night-eighties.git
```
